# Cajaindependencia — raíz del repositorio

El proyecto Java EE (`Sindicato.war`: JSF 2.3 + Hibernate 4.3 + MySQL, Tomcat 8 bajo `/Sindicato`)
vive en el subdirectorio **`caja-independencia/`**. Esta raíz solo agrupa el repo, los certificados
MySQL y hojas de cálculo de referencia.

**Todo el contexto de trabajo está en `caja-independencia/CLAUDE.md` y `caja-independencia/.claude/docs/`.**
Las rutas relativas mencionadas en esos documentos (`src/main/...`, `.claude/docs/...`) son relativas
a `caja-independencia/`, no a esta raíz.

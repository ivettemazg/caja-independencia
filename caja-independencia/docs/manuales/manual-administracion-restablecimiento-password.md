# Manual de administracion: Restablecimiento de password

Este manual explica como restablecer el password de un empleado desde el modulo de administracion.

## Cuando usar esta opcion

Usa esta opcion cuando un empleado no pueda recuperar su acceso por correo o cuando el area de administracion necesite asignarle un password temporal.

Ejemplos:

- El empleado no tiene correo registrado.
- El empleado no recuerda su password y no puede usar la recuperacion por correo.
- El empleado requiere apoyo directo de administracion para recuperar el acceso.

## Antes de iniciar

Necesitas contar con:

- Acceso al modulo de administracion.
- Clave de empleado.
- Empresa del empleado.
- Confirmacion de que estas atendiendo al empleado correcto.

Por seguridad, antes de restablecer el password valida la identidad del empleado conforme al procedimiento interno de la organizacion.

## Como restablecer el password

1. Ingresa al sistema con un usuario administrador.
2. Abre el **Panel de administrador**.
3. Entra a la pestaña **Empleados**.
4. Captura la **Clave de empleado**.
5. Selecciona la **Empresa**.
6. Da clic en **Buscar**.
7. Verifica que la informacion mostrada corresponda al empleado correcto.
8. En el campo **Nuevo password (opcional)** puedes hacer una de estas dos acciones:
   - Capturar un password temporal.
   - Dejar el campo vacio para que el sistema genere un password temporal automaticamente.
9. Da clic en **Resetear contraseña**.
10. El sistema mostrara el nuevo password en pantalla.

## Que hacer despues de restablecerlo

Entrega el password temporal al empleado por un medio seguro.

Recomienda al empleado:

- Entrar al sistema lo antes posible.
- Cambiar el password temporal por uno propio.
- No compartir su password con otras personas.
- Verificar que su correo este actualizado en su informacion personal.

## Consideraciones importantes

- El restablecimiento administrativo cambia el password directamente.
- Esta opcion no envia correo automaticamente al empleado.
- Si capturas un password manual, ese sera el nuevo password del empleado.
- Si dejas el campo vacio, el sistema genera un password temporal y lo muestra en pantalla.
- El password generado o capturado debe comunicarse al empleado de forma segura.
- Antes de usar esta opcion, confirma que el empleado seleccionado sea el correcto.
- Si el empleado tiene correo registrado y actualizado, tambien puede usar la opcion **¿Olvidaste tu contraseña?** desde el login.

## Mensajes que puedes ver

**No se encontro el empleado**  
La clave de empleado no corresponde a la empresa seleccionada o el empleado no existe en el sistema.

**Capture clave y empresa**  
Falta capturar la clave de empleado o seleccionar la empresa.

**Contraseña restablecida: [password]**  
El password fue actualizado correctamente. El texto mostrado despues de los dos puntos es el nuevo password del empleado.

**No fue posible restablecer la contraseña**  
Ocurrio un problema al intentar actualizar el password. Intenta nuevamente. Si el problema continua, reportalo al area tecnica.

## Buenas practicas

- No restablezcas passwords sin validar la identidad del empleado.
- No envies passwords por canales publicos o compartidos.
- No guardes passwords temporales en notas visibles o documentos sin proteccion.
- Evita usar passwords faciles de adivinar.
- Pide al empleado confirmar que pudo entrar correctamente.
- Si el empleado ya actualizo su informacion personal, su correo debe quedar listo para futuras recuperaciones desde el login.
